# Barbearia Stylos

Site institucional responsivo desenvolvido para a **Barbearia Stylos**, localizada em Caxias do Sul — RS.

O projeto apresenta os serviços oferecidos, tabela de preços, galeria de trabalhos realizados, informações do estabelecimento e agendamento direto pelo WhatsApp.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Design responsivo
- Imagens otimizadas em WebP

## Funcionalidades

- Layout moderno com identidade visual em preto e dourado
- Navegação responsiva para computadores, tablets e celulares
- Apresentação dos serviços e valores
- Carrossel de fotografias reais
- Galeria com filtros por categoria
- Visualização ampliada das fotografias
- Agendamento pelo WhatsApp
- Links para Instagram e Facebook
- Informações de localização e horários de atendimento
- Otimização de imagens para melhor desempenho

## Estrutura do projeto

- `index.html` — estrutura e conteúdo
- `style.css` — estilos e responsividade
- `script.js` — funcionalidades e interações
- `assets/` — logotipo e imagens
- `assets/galeria/` — fotografias dos trabalhos realizados

## Como executar

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` no navegador.

Não é necessário instalar dependências ou configurar um banco de dados.

## Atualização da galeria

As fotografias são armazenadas em `assets/galeria/`.

Para adicionar novas imagens, atualize a lista `photos` no arquivo `script.js` e publique as alterações.

O carrossel e a galeria utilizam a mesma coleção de fotografias.

## Publicação

O projeto pode ser hospedado gratuitamente no GitHub Pages, Cloudflare Pages ou Netlify.

## Observações

Os serviços, preços, horários e informações comerciais devem ser confirmados com o estabelecimento antes da publicação definitiva.

As fotografias utilizadas pertencem ao acervo da Barbearia Stylos e são utilizadas com autorização. Não devem ser reutilizadas em outros projetos sem permissão.
